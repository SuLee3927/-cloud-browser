# 云浏览器 · 家里电脑启动备忘

> 忘了怎么弄的时候，看这个文件就行。

---

## 平时只用做这一件事

**双击文件夹里的 `start-hidden.vbs`**

- 没有窗口弹出，这是正常的
- 后台会做两件事：启动专用 Chrome + 建立到服务器的隧道
- 不用管它，也别删它

验证成功（随便哪一条）：
- 服务器上 `ss -ltn | grep 9223` 能看到监听
- 任务管理器里能看到 `ssh.exe` 和 Chrome 在跑

## 如果哪天要重装（比如换了电脑）

### 第一步：生成钥匙

```powershell
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\cloudbrowser" -N '""' -C cloud-browser
type "$env:USERPROFILE\.ssh\cloudbrowser.pub"
```

把公钥发给服务器管理员，加到 `~/.ssh/authorized_keys`（限制写法见 `server/authorized_keys.example`）。

### 第二步：改服务器地址

记事本打开 `home-bridge.cmd`，确认这三行：

```
set "SERVER=user@your-server.example.com"
set "PORT=22"
set "KEY=%USERPROFILE%\.ssh\cloudbrowser"
```

### 第三步：跑起来

- 平时：双击 `start-hidden.vbs`
- 排查问题：双击 `home-bridge.cmd`（有窗口，能看到报错）

## 电源设置（管理员 PowerShell，跑一次就行）

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
powercfg /change disk-timeout-ac 0
powercfg /change monitor-timeout-ac 10
powercfg /setacvalueindex SCHEME_CURRENT 4f971e89-eebd-4455-a8de-9e59040e7347 5ca83367-6e45-459f-a27b-476b1d01c936 0
powercfg /setactive SCHEME_CURRENT
```

含义：插电时**永不睡眠**、不休眠、硬盘不歇；屏幕 10 分钟关（屏幕关了机器还在跑）；合盖不睡。
（某条报错就跳过，不影响主要效果。）

## 开机自启（做一次）

```powershell
Copy-Item ".\start-hidden.vbs" "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\" -Force
```

装好后**开机就会自动连**，什么都不用点。

## 出问题怎么查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 服务器说"主机不在线" | 隧道断了 | 双击一次 `start-hidden.vbs` |
| 双击 VBS 后没反应 | 可能本来就在跑 | 等一下，让服务器侧验证 |
| Chrome 没启动 | 路径不对 | 用 `home-bridge.cmd` 跑，看窗口报错 |
| 隧道反复重连 | 网络不稳 | 正常，它自己会重连 |
| 想彻底停掉 | — | 任务管理器结束 `ssh.exe`（Chrome 可单独关） |

---

## 别做的事

- ❌ 别删这个文件夹（开机自启指着它）
- ❌ 别把密钥文件删了（隧道要用）
- ❌ 别在专用 Chrome 里登你自己的日常账号（会跟你自己的浏览器打架）
- ⚠️ 关窗口时看清楚——别把跑隧道的那个关了（用 `start-hidden.vbs` 启动就没这问题）
